01 / Run it locally

Your first mesh,
on your computer.

Start the server and console, OIDC sign-in, PostgreSQL, two fleet machines, and Ollama. The images are pulled from the project’s published container registry.

Bring: Git, Docker with Compose or Podman with a Compose provider, several GB of disk, and free localhost ports 19999 and 20000. For a small CPU model, 8 GB+ RAM is recommended.

Follow the guided quickstart →
LOCAL DEMO / TERMINAL
git clone https://github.com/joeyenfield/ai-coding-agent-proxy.git
cd ai-coding-agent-proxy
docker compose -f quickstart/compose.yaml up -d

Using Podman? Replace docker compose with podman compose. On Windows/macOS, start your Podman machine first.

  1. Open localhost:19999. Sign in with admin / secret.
  2. Add machine-1’s Ollama as a provider, pull a model, then launch an agent. No model is downloaded automatically.

Local demo only. Uses known credentials and loopback ports. For a real deployment, configure your own secrets, HTTPS, and sign-in service. Production setup →

05 / Open source. Explicit trust.

Own the deployment.
Understand the responsibility.

MIT licensed, with source you can inspect and change. Self-host the server and choose who can access recordings, machines, and tools.

Access belongs to people

Mandatory OIDC sign-in, organizations and teams, private or shared sessions, and per-machine feature grants. Remote launches and shells also require the machine’s own switches and allowed folders.

Accounts and permissions →

Traces can contain sensitive data

Full tracing is opt-in. Saved bodies can contain code, prompts, responses, and secrets; they are not generally redacted. Set retention for payloads and terminal history, restrict sharing, and protect the database and backups.

Storage and retention →

Trust the server you connect to

Account-agent capture decrypts HTTPS on the server using its CA, trusted only by the launched process tree. Hosted traffic still reaches its vendor. Use TLS, keep providers on loopback, and grant remote execution carefully.
