01 / Any agent, any machine

Your favorite agents.
Any machine, any device.

Start an agent on any machine in your fleet and its terminal comes with it. Read it, type into it and answer it from a browser or phone, while it runs next to your code and models. These three are real: started from the console on one laptop, all on its Ollama.

Start it where the work is

Pick a machine and an agent on Start an agent. It starts in a folder the machine’s owner allows and appears in Live agent view next to your other agents.

Runs where
your code does.

Any computer that runs agents or models joins the same fleet. Add a machine in the console gives you one command for that system.

LINUX · MACOS · WINDOWS · FREEBSD

One-line install

Installs agent-machine (and agent, if you start agents there), verified against the server’s SHA-256. It can start at boot.

The same programs and commands as a pip package, for computers without a Go build, including Termux on Android.

These are the shipped routes. A supported protocol doesn’t guarantee that every agent version, model or tool call works well, so test your combination.

Set context on the model server. llama.cpp uses llama-server in router mode. ‡ OpenAI and Anthropic-compatible APIs: hosted (OpenAI, Anthropic, OpenRouter, LiteLLM Proxy, Groq, DeepSeek, Azure OpenAI, ...) or on your machines (LM Studio, vLLM, SGLang). Each is set up with the protocols it speaks; requests pass through untranslated. Compatibility notes →

2. Hosted API forwarding

claude-subscription forwards Claude Code’s Anthropic API calls using the agent’s own credentials. Other traffic, such as OAuth and telemetry, can go directly to the vendor. This is not a general gateway for every cloud API.

3. Vendor-account capture

claude-account, codex-account and copilot-account keep using their vendor services. The server decrypts permitted proxied traffic using a CA trusted by the launched process tree. Review that trust boundary.

Local model routing does not make the whole agent offline. Agents and tools can still contact external services. MCP support also varies: Aider cannot attach shared MCP servers. Agent setup → · Provider reference →
